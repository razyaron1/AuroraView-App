\# AuroraView - Time and Material Reporting System



AuroraView is a full-stack Web Application built with \*\*React\*\*, \*\*TypeScript\*\*, \*\*Vite\*\*, and \*\*Firebase\*\* (Firestore \& Auth) designed for managing contractor time logs, material expenses, site locations, and invoice generation.



\---



\## 🚀 Key Features



\* \*\*Authentication \& Role Management:\*\* Secure sign-in/registration with Admin (`razy@auroraview.com`) privileges.

\* \*\*Time \& Material Logging:\*\* Easily submit hours worked or material expenses assigned to specific site locations.

\* \*\*Contractor Directory \& Rates:\*\* Admin management for contractor rates, addresses, account password updates, and last login tracking.

\* \*\*Month Lock Security:\*\* Lock specific months to prevent historical record edits or deletions.

\* \*\*Customizable Site Locations:\*\* Add, edit, or remove work sites dynamically.

\* \*\*Automated Invoice Generator:\*\* Per-contractor invoice compilation with customizable sequence numbering and PDF/Print output support.



\---



\## 🛠️ Tech Stack



\* \*\*Frontend:\*\* React, TypeScript, Vite, Lucide Icons

\* \*\*Backend / Database:\*\* Firebase Authentication, Cloud Firestore

\* \*\*Deployment:\*\* Vercel / GitHub Pages
